# 📖 Инструкция по запуску бота VW Lavida

## Что у вас есть в папке:
- `bot.py` — код бота
- `document.md` — руководство по VW Lavida
- `requirements.txt` — список библиотек
- `railway.toml` — настройки хостинга

---

## Шаг 1 — Получить токен Telegram-бота

1. Откройте Telegram, найдите **@BotFather**
2. Напишите `/newbot`
3. Введите имя бота (например: `Lavida Helper`)
4. Введите username (например: `lavida_helper_bot`)
5. Сохраните токен — он выглядит так: `7123456789:AAF-abc123...`

---

## Шаг 2 — Получить ключ Anthropic API

1. Зайдите на https://console.anthropic.com
2. Зарегистрируйтесь (бесплатно)
3. Перейдите в **API Keys** → **Create Key**
4. Скопируйте ключ — он выглядит так: `sk-ant-api03-...`

> ⚠️ Anthropic даёт $5 бесплатного кредита новым пользователям.

---

## Шаг 3 — Загрузить на Railway и запустить

1. Зайдите на https://railway.app
2. Нажмите **Login** → войдите через GitHub (создайте аккаунт если нет)
3. Нажмите **New Project** → **Deploy from GitHub repo**
   - Если нет репозитория: нажмите **Deploy a template** → выберите **Empty**
   - Затем перетащите папку с файлами через интерфейс

### Альтернативный способ (проще): через GitHub

1. Зайдите на https://github.com → создайте новый репозиторий (назовите `lavida-bot`)
2. Загрузите все 4 файла из папки в репозиторий
3. На Railway: **New Project** → **Deploy from GitHub** → выберите ваш репозиторий

---

## Шаг 4 — Добавить секретные переменные

В Railway, зайдите в ваш проект → вкладка **Variables** → добавьте:

| Название | Значение |
|----------|----------|
| `TELEGRAM_BOT_TOKEN` | ваш токен из шага 1 |
| `ANTHROPIC_API_KEY` | ваш ключ из шага 2 |

Нажмите **Deploy** — бот запустится автоматически!
